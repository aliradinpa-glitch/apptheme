# 🛍️ اپ‌تم (apptheme.ir) — فروشگاه قالب + سفارش اپلیکیشن

> **نسخه حرفه‌ای 1.7:** بهبود پوسته فروشگاه و پنل، دسترس‌پذیری و focus states، استقرار Docker/Render دقیق‌تر، JSON-LD امن‌تر، مسیرهای فایل سازگارتر با ویندوز/Linux، healthcheck کانتینر و تست‌های قابل اجرای پروژه.

فروشگاه حرفه‌ای فروش قالب با پنل ادمین کامل، تخفیف هوشمند مناسبت‌های شمسی، پیام‌رسانی، و بخش سفارش ساخت اپلیکیشن اندروید با برآورد هوشمند قیمت.

> **استک:** Node.js خالص (صفر وابستگی npm) + دیتابیس JSON اتمیک + SSR کامل برای سئو
> اجرا فقط با `node server.js` — بدون npm install، بدون داکر، بدون دیتابیس خارجی.

## 🚀 اجرا

```bash
node server.js                      # http://localhost:3000
PORT=8080 node server.js            # پورت دلخواه
SITE_URL=https://apptheme.ir node server.js   # در پروداکشن (کانونیکال/sitemap/لینک ایمیل‌ها)
```

## ✨ امکانات

### فروشگاه
- ویترین، فیلتر (دسته/فریمورک/جستجو/مرتب‌سازی)، صفحه محصول با **لایک + نظر + امتیاز ستاره‌ای**
- **پیش‌نمایش زنده هر قالب**: `/templates/{slug}/preview` (سایت ۳‌صفحه‌ای تولیدشده از دیتای محصول)
- سبد خرید → تسویه با **کد تخفیف** + **تخفیف خودکار مناسبت‌ها** → درگاه دمو → **دانلود آنی ZIP** (لینک توکن‌دار)
- مهمان‌ها در تسویه به ثبت‌نام با کد `WELCOME10` هدایت می‌شوند
- حساب کاربری: سفارش‌ها، دانلودها، پروژه‌های اپ، **پیام با پشتیبانی**
- صفحه **قوانین سایت** (`/terms`)

### تخفیف هوشمند مناسبت‌ها (تقویم شمسی)
- تشخیص خودکار تاریخ (نوروز، حراج تابستانه، هفته پاییز، یلدا، دهه فجر)
- اعمال خودکار روی محصولات بدون تخفیف + قابل ویرایش/اجبار روشن‌خاموش از ادمین

### سفارش اپ اندروید (`/apps`)
- **بودجه‌سنج هوشمند**: پرامپت فارسی → تشخیص ویژگی‌ها → بازه قیمت + زمان + بیعانه
- گردش کار: بیعانه ۳۰٪ → ۳ پیش‌نمایش مرحله‌ای با **نوار پیشرفت** → نقطه ۷۰٪ (ادامه با ۳۰٪ دوم یا انصراف با کسر ۴۰٪ و بازگشت وجه) → ۴۰٪ پایانی بعد از تحویل
- اطلاع‌رسانی هر مرحله با پیام سیستمی به کاربر

### پنل ادمین (`/admin`)
داشبورد (نمودار فروش ۳۰ روزه، آمار کامل) · CRUD قالب‌ها · سفارش‌ها (تغییر وضعیت + صدور لینک دانلود) · مشتریان (مسدودسازی + هشدار تأییدنشده‌ها) · نظرات (تأیید/رد) · کدهای تخفیف · سفارش‌های اپ (وضعیت، پیش‌نمایش، پیام) · پیام‌رسانی دوطرفه · تنظیمات (پرداخت زرین‌پال، SMTP، مناسبت‌ها)

## 🛡️ امنیت
scrypt + salt · CSRF سراسری (فرم‌ها + API + ادمین) · Rate-limit · CSP بدون اسکریپت inline · کوکی HttpOnly/SameSite · ضد XSS/path-traversal · گارد نقش‌ها · لینک دانلود توکن‌دار

## 🔍 سئو
SSR کامل · متا/OG/کانونیکال · sitemap.xml خودکار · robots.txt · JSON-LD (Product/Rating/WebSite) · HTML معنایی و فونت preload

## 🚀 دیپلوی (هاست رایگان → هر جا)

→ راهنمای کامل فارسی: **[DEPLOY.md](DEPLOY.md)**

- **رایگان:** Render.com (فایل `render.yaml` آماده است) یا Koyeb
- **مهاجرت بعدی:** ادمین → تنظیمات → «دانلود پشتیبان» → در هاست جدید «بازیابی» — همین!
- **Docker/VPS:** `Dockerfile` آماده است؛ روی VPS فقط `node server.js`
- gzip سراسری فعال (HTML/CSS/JS/ZIP ~۸۷٪ کوچکتر) — مناسب پهنای باند محدود هاست رایگان
- قالب‌های تولیدی بدون عکس رستری: فقط SVG/CSS (ZIP هر قالب ~۲۰KB، پیش‌نمایش ~۱۰KB)

### 🧙 سفارش اپ (فاز ۵)
- **ویزارد ۶ مرحله‌ای** سوال‌جواب هوشمند → مشخصات در **فایل JSON کم‌حجم (~۰.۶KB)** ذخیره می‌شود
- ادمین در داشبورد: **تایید پرامپت + قیمت‌گذاری نهایی** (یا رد با دلیل) → اعلام خودکار به مشتری
- قیمت‌گذاری **منصفانه** متناسب با حجم (پایه ۳.۵M + ۴۵۰k/ویژگی)
- **۱۰٪ پاداش وفاداری** به کیف پول در صورت ماندن تا پایان
- نارضایتی پس از تحویل → **۹۰٪ به کیف پول** + **برداشت خودکار** به شبا (اعتبارسنجی سخت سمت سرور)
- انصراف در ۷۰٪ → ۶۰٪ به کیف پول

### 📱 اپ موبایل (PWA)
- نصب‌شدنی روی اندروید/iOS (آیکون، حالت standalone، صفحه آفلاین)
- Service Worker با کش هوشمند؛ صفحات مالی/ادمین هرگز کش نمی‌شوند (امنیت)
- منیفست RTL + میانبرهای سریع
