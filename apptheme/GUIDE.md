## ۳) امتحان قابلیت‌های جدید (قدم‌به‌قدم)

### 🚪 مودال ورود حرفه‌ای
1. در هدر سایت روی «ورود» بزن.
2. مودال بزرگ دوپنلی باز می‌شود؛ **هیچ اسکرولی در صفحهٔ پشت نیست** و دقیقاً وسط است.
3. دکمهٔ «فراموشی رمز عبور 🔑» داخل فرم → وضعیت بازیابی باز می‌شود (همان مودال).
4. دکمهٔ «ثبت‌نام کنید» → وضعیت ثبت‌نام با **نوار قدرت رمز** (۴ قسمتی).
5. آیکن 👁 کنار رمز → نمایش/مخفی رمز.

### 🔑 دکمهٔ بازیابی در هدر
- وقتی وارد نشده‌ای، در هدر یک دکمهٔ 🔑 هست (کنار «ورود») → همان مودال را با وضعیت بازیابی باز می‌کند.

### 🛒 سبد خرید
1. یک قالب به سبد اضافه کن و برو به `/cart`.
2. هر ردیف: تصویر بندانگشتی + تعداد + مبلغ + **دکمهٔ حذف قرمز ✕** (با پنجرهٔ تأیید).
3. دکمهٔ «🧹 خالی کردن سبد» بالای صفحه.
4. در کشوی سبد (گوشهٔ صفحه) هم دکمهٔ حذف روی هر آیتم هست + **بازگردانی** بعد از حذف.

### 🪄 قالب‌ساز هوشمند (ادمین → قالب‌ساز)
1. پرامپت بنویس (مثلاً «سایت رستوران لوکس برند شب طلایی»).
2. **سبک طراحی را انتخاب کن** (یا «✨ خودکار» بگذار تا AI خودش انتخاب کند).
3. «تولید قالب» → پیش‌نمایش زنده همان لحظه عوض می‌شود. با سبک‌های مختلف تولید کن و تفاوت را ببین:
   - نئون سایبری (شب + خطوط نئون) / گلاس (شیشه‌ای + هاله پاستلی) / بروتالیست (لبه تیز + سایه آفست بولد) / لوکس (طلایی + سریف) / سایبرپانک (سایان + ماجنتا) / اورورا (پاستلی شاد) / ادیتوریال (مجله‌ای) / مینیمال (سفید و خلوت)
4. «انتشار در فروشگاه» → قالب با همان سبک به فروشگاه اضافه می‌شود.

## ۴) استقرار روی سرور شخصی (VPS) — راهنمای کامل

> VPS یعنی یک سرور مجازی که اجاره می‌کنی و کنترل کامل داری.
> پیشنهاد: هتزنر (Hetzner) یا کانتینو (Contabo) — ارزان و مطمئن.

### قدم ۱: بالا آوردن سرور
- سیستم‌عامل: **Ubuntu 24.04** (یا 22.04)
- حجم سرور: ۱ هسته / ۲ گیگ رم / ۲۰ گیگ دیسک کافی است (پروژه خیلی سبک است).

### قدم ۲: ورود به سرور (SSH)
از کامپیوتر خودت (PowerShell در ویندوز یا ترمینال در مک/لینوکس):

```bash
ssh root@IP-SERVER
```

### قدم ۳: نصب Node.js
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs
node -v     # باید v20.x نمایش بدهد
```

### قدم ۴: انتقال پروژه به سرور
**روش الف — گیت‌هاب** (اگر پروژه را پوش کرده‌ای):
```bash
cd /opt
git clone https://github.com/aliradinpa-glitch/apptheme.git
cd apptheme/apptheme      # پوشهٔ اصلی پروژه داخل ریپو
```

**روش ب — آپلود ZIP** (ساده‌تر برای مبتدی):
- فایل `apptheme-aura-v3.zip` را در کامپیوترت باز کن و از همین صفحه دانلود کن.
- با **WinSCP** (ویندوز) یا `scp` آن را به سرور بفرست:
```bash
scp apptheme-aura-v3.zip root@IP-SERVER:/opt/
# روی سرور:
cd /opt && unzip apptheme-aura-v3.zip -d apptheme && cd apptheme/apptheme
```

### قدم ۵: انتقال دیتابیس (مهم!)
همهٔ قالب‌ها، سفارش‌ها و کاربران داخل **یک فایل** است: `data/db.json`

- اگر سایتت قبلاً کار می‌کرده: همین فایل `data/db.json` را از پروژهٔ قبلی (یا از «پشتیبان» در پنل ادمین) در سرور جایگزین کن.
- اگر نصب تازه است: نیازی نیست — با اولین اجرا، دیتابیس نمونه با حساب مدیر ساخته می‌شود.

### قدم ۶: اجرای حرفه‌ای با PM2 (دائم روشن بماند)

```bash
npm install -g pm2
cd /opt/apptheme/apptheme
pm2 start server.js --name apptheme --time
pm2 save                       # ذخیرهٔ وضعیت
pm2 startup                    # اجرای خودکار بعد از ریبوت سرور
```

### قدم ۷: تنظیم متغیرها
```bash
pm2 restart apptheme --update-env
# یا با فایل اکوسیستم: (پیشنهادی)
pm2 start ecosystem.config.js
```
فایل `ecosystem.config.js` (در پوشهٔ پروژه):
```js
module.exports = {
  apps: [{
    name: 'apptheme',
    script: 'server.js',
    env: {
      PORT: 3000,
      SITE_URL: 'https://YOUR-DOMAIN.com',
    },
  }],
};
```

### قدم ۸: دامنه + SSL (ایمن)
ساده‌ترین راه: **Caddy** (SSL خودکار):
```bash
apt-get install -y caddy
echo "YOUR-DOMAIN.com {
    reverse_proxy 127.0.0.1:3000
}" > /etc/caddy/Caddyfile
systemctl restart caddy
```

### قدم ۹: چک‌لیست نهایی
- [ ] `SITE_URL` با دامنهٔ واقعی (HTTPS)
- [ ] رمز ادمین قوی (رمز پیش‌فرض را عوض کن!)
- [ ] تنظیمات → SMTP (برای ایمیل تأیید و بازیابی رمز) — راهنمای گوگل: تنظیمات → «App Password»
- [ ] تنظیمات → پرداخت → مرچنت‌کد زرین‌پال
- [ ] بکاپ دوره‌ای: هر شب `data/db.json` را کپی کن:
```bash
crontab -e
# این خط را اضافه کن:
0 3 * * * cp /opt/apptheme/apptheme/data/db.json /root/backup/db-$(date +\%F).json
```

## ✨ نسخهٔ ۳.۱ — استودیوی هوش مصنوعی + اشتراک پرو کاربران

### 🧠 هوش مصنوعی در دو سطح (ادمین مافوقحرفهای / کاربر پرو)
- **ادمین (تو)**: قدرت هوش مصنوعی = از ٪۶۲ (برنزی) تا **٪۱۰۰ (اپیک)** — مافوقحرفهای.
- **کاربران با اشتراک پرو**: قدرت = طبق پلنشان، از ٪۱۲ تا **٪۵۰ (بهترین پلن = دقیقاً نصف قدرت ادمین)**.
- این درصدها واقعاً روی خروجی اثر میگذارد: تعداد بخشها/محصولات/کارتها، افکتها، انیمیشنها و تبهای اضافه (مثل تب تخفیفها در اپ که فقط در قدرت بالا میآید).

### 👥 پلنهای پرو — تنظیم از سمت مدیریت
- صفحهٔ جدید **«پلنهای پرو»** در پنل ادمین (`/admin/ai-pro`): برای هر ۶ پلن (برنزی/نقرهای/طلایی/VIP/لجندری/اپیک) میتوانی **قیمت ماهانه + ٪قدرت هوش مصنوعی + مدت + فعال/غیرفعال** را تعیین کنی و ذخیره کنی.
- کاربر از `/ai` اشتراک میخرد (پرداخت مستقیم از کیف پول) و بلافاصله استودیو فعال میشود: قالبساز، افزونهساز، فروشگاهساز و **اپ اندروید** — با قدرت طبق پلنش.

### 🎲 خروجیهای متنوع + ✍️ ویرایش مجدد (برای ادمین و کاربران)
- بعد از هر ساخت: دکمهٔ **«🎲 متفاوت»** → نسخهٔ دیگری با چیدمان/شعار/پالت متفاوت از همان پرامپت.
- کادر **«✍️ ویرایش»** → دستور فارسی بنویس؛ هوش مصنوعی میفهمد و اعمال میکند، مثلاً:
  - «رنگ اصلی آبی کن» / «حالت تیره» / «سبک لوکس» / «برند شود گلستان» / «بخش گالری اضافه کن» / «حذف نظرات» / «شعار: طعمی متفاوت»
- هر نسخهٔ جدید، یک فایل ZIP جدا با پیشنمایش است و در «ساختههای من» ذخیره میشود (نسخهها نگه داشته میشوند).

### 👁 پیشنمایش برای همهٔ خروجیها + ⏱ زمان تخمینی
- همهٔ خروجیها (قالب/افزونه/فروشگاهساز/اپ) **هم فایل ZIP دارند هم پیشنمایش زنده** (`/preview/ai/…`).
- قبل و حین ساخت، **زمان تخمینی** اعلام میشود؛ در تحلیل اولیه هم قیمت + زمان میآید.

### 📱 اپ اندروید — حرفهایتر
- PWA نصبشدنی (manifest + icon + **Service Worker آفلاین**) + ناوبری تبدار + سبد + تب تخفیفها (در قدرتهای بالا) + راهنمای Word نصب گوشی/آیفون.

### 📶 بدون وابستگی به سایتهای خارجی
- هیچ خروجی هوش مصنوعی از CDN یا سرویس خارجی استفاده نمیکند (Tailwind/Bootstrap/فونت Vazirmatn همگی **جاسازیشدهٔ محلی** هستند) — با قطع اینترنت بینالمللی، ساخت، پیشنمایش و دانلود همه کار میکنند.
- «سایت از لینک» فقط خودِ لینکی را که کاربر میدهد میخواند (بدون پروکسی خارجی)؛ اگر سایت در دسترس نباشد، پیام شفاف فارسی + پیشنهاد جایگزین میدهد.

### 📱 ریسپانسیوی مافوقحرفهای

- خود سایت اصلی هم بلوک «بیمهٔ ریسپانسیو» گرفت (جدولها، گرید محصولات، فرمها، مودالها و استودیو در موبایل).

## ✨ نسخهٔ ۳.۲ — سبد مافوق‌حرفه‌ای + منوی استاندارد + انتشار اپ

### سبد خرید (از این‌به‌بعد فروشگاه واقعی!)
- **کشوی سبد در همهٔ صفحات**: با کلیک روی سبد (بالای سایت) کشویی از کنار صفحه باز می‌شود؛ بدون رفرش می‌توانی تعداد را کم/زیاد کنی، حذف کنی (با «بازگردانی»!) و مستقیم تسویه کنی.
- **جزئیات حرفه‌ای**: عکس محصول، قیمت واحد و جمع هر ردیف، **سود شما از تخفیف‌ها**، نوار پیشرفت «تا ارسال رایگان»، جمع نهایی و دکمه‌های استاندارد تسویه.
- صفحهٔ کامل سبد هم حرفه‌ای شد: خلاصهٔ سفارش چسبان کنار لیست، درصد تخفیف هر کالا، پیام‌های اطمینان (پرداخت امن، دانلود آنی، پشتیبانی).

### منو و دکمه‌ها
- **ایموجی‌ها از منوها حذف شدند**؛ دکمه‌های استاندارد و تمیز در همهٔ صفحات.
- **زیرمنو (منوی کشویی)** برای «قالب‌ها» (همه/دسته‌ها/پرفروش/تخفیف‌دار)، «هوش مصنوعی» (قالب‌ساز/افزونه/فروشگاه/تبدیل/لینک/اپ/اشتراک پرو) و «سفارش اپ» (سفارش/انتشار/پروژه‌های من).
- لینک‌های زیرمنو مستقیم به همان بخش می‌روند (مثلاً `/ai#tab-plugin` خودش تب افزونه را باز می‌کند) — **هیچ دکمهٔ کوری وجود ندارد**.

### انتشار اپ (پاسخ به درخواست «کجا منتشر کنم؟»)
- **صفحهٔ کاربر**: `مسیر: سفارش اپ ← انتشار اپ` (یا `/apps/publish`) — همهٔ خروجی‌های هوش مصنوعی‌ات آن‌جاست؛ با یک کلیک «انتشار» لینک عمومی می‌گیری، هر وقت خواستی «توقف انتشار».
- **صفحهٔ عمومی**: `/app/…` — پیش‌نمایش زندهٔ اپ برای همه + دکمهٔ کپی لینک + راهنمای نصب روی موبایل.
- **پنل ادمین**: منوی جدید «انتشار اپ‌ها» (`/admin/apps`) — فهرست کامل خروجی‌های همهٔ کاربران با فیلتر (نوع/وضعیت/زمان ساخت) و دکمه‌های انتشار/توقف/پیش‌نمایش/دانلود.

### هوش مصنوعی — دقیق‌تر و حرفه‌ای‌تر
