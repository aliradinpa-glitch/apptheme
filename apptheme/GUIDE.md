# 🚀 راهنمای کامل و مبتدی‌پسند — اپ‌تم نسخه «نئون ریفت» 2.0

> این راهنما طوری نوشته شده که حتی اگر تا حالا برنامه‌نویسی نکرده‌ای، بتوانی پروژه را اجرا کنی،
> رنگ‌ها را عوض کنی و نسخه جدیدت را روی گیت‌هاب بگذاری.

## ۱) چه چیزهایی عوض شد؟ (خلاصه تغییرات)

| بخش | قبل | بعد (نئون ریفت 2.0) |
|---|---|---|
| تم تیره | تیره و تخت | بنفش‌سرمه‌ای روشن‌تر + هاله‌های نورانی |
| پس‌زمینه | ثابت | **خطوط نازک نئونی متحرک** (مثل شبکه سایبری) + هاله‌های رنگی شناور |
| ناوبار فروشگاه | ساده | شیشه‌ای (Glass)، خط گرادیان متحرک زیر منو، لوگوی انیمیشنی |
| منوی ادمین | لیست ساده | **گروه‌بندی‌شده** (مدیریت/فروشگاه/سرویس‌ها/...)، آیتم فعال با گرادیان+ریشه نورانی |
| کارت‌های آمار | آیکن ساده | آیکن نئونی با رنگ‌های متفاوت، خط گرادیان کنار کارت |
| صفحه‌بندی | دکمه‌های خام | **صفحه‌بندی حرفه‌ای**: صفحهٔ اول/قبلی/شماره‌ها با «...»/بعدی/آخر + خط «نمایش ۱ تا ۱۵ از ۶۰» |
| مودال‌ها | ساده و زشت | **مودال حرفه‌ای**: آیکن شناور، هدر گرادیان متحرک، دکمهٔ خطرناک قرمز، انیمیشن ورود/خروج |
| اعلان‌ها (Toast) | متن ساده | اعلان با **آیکن، عنوان، نوار پیشرفت زمان**، توقف با هاور (۴ نوع: موفق/خطا/هشدار/اطلاع) |
| هشدارها (Alert) | رنگ زمینه | **باکس شیشه‌ای با خط نئونی کنار** و هالهٔ رنگی |
| بندانگشتی قالب‌ها | همه یک شکل | **۴ لایوت متفاوت** (مرورگر، موبایل، داشبورد تیره، لندینگ) |
| پنل ادمین | بدون اعلان | **زنگ اعلان با دراپ‌داون** (پیام‌ها/نظرات/پروژه‌ها/برداشت‌ها) + شمارنده پالس‌دار |
| منوی کاربر | ندارد | منوی کشویی کاربر با خروج (با CSRF امن) |
| صفحه ۴۰۴ | ساده | با استایل نئونی و دو دکمه |

## ۲) اجرا روی کامپیوتر خودت (خیلی ساده)

**قدم ۱:** نصب Node.js
- برو به سایت `nodejs.org` و نسخهٔ LTS را دانلود و نصب کن (دکمهٔ Next و Finish).

**قدم ۲:** باز کردن ترمینال در پوشهٔ پروژه
- داخل پوشهٔ پروژه، راست‌کلیک → «Open in Terminal» (یا در پوشه تایپ کن `cmd` و Enter).

**قدم ۳:** اجرا (فقط یک دستور):

```bash
node server.js
```

**قدم ۴:** مرورگر را باز کن:
- فروشگاه:  `http://localhost:3000`
- پنل ادمین: `http://localhost:3000/setup` (بار اول حساب مدیر بساز)
- بعد از ساخت مدیر: `http://localhost:3000/admin`

> ⚠️ نیازی به `npm install` نیست! این پروژه **صفر وابستگی** دارد.

## ۳) عوض کردن رنگ‌ها و ظاهر (بدون دانش برنامه‌نویسی)

همهٔ رنگ‌ها در **یک جای مشخص** تعریف شده‌اند؛ فقط همین را عوض کن:

### فروشگاه → فایل `src/assets/css/app.css` (خط‌های اول)
```
--primary: #7c5cff;   ← رنگ اصلی (بنفش)
--primary-2: #22d3ee; ← رنگ دوم (فیروزه‌ای)
--primary-3: #f472b6; ← رنگ سوم (صورتی)
```
مثلاً می‌خواهی سبز نئونی باشد؟ این را بنویس:
```
--primary: #22c55e; --primary-2: #a3e635; --primary-3: #06b6d4;
```

### پنل ادمین → فایل `src/assets/css/admin.css` (همان خط‌ها)

### پس‌زمینهٔ خطوط نئونی
در هر دو فایل، بخش `.bg-fx::before` همین است:
```css
background:
  repeating-linear-gradient(90deg, transparent 0 79px, color-mix(...) 80px, transparent 81px),
  repeating-linear-gradient(0deg, transparent 0 79px, ... 80px, transparent 81px);
animation: gridDrift 26s linear infinite;
```
- عدد `79px` = فاصلهٔ خطوط (بزرگ‌تر = خطوط دورتر)
- `26s` = سرعت حرکت (بزرگ‌تر = آرام‌تر)
- خطوط را حذف می‌خواهی؟ کل `.bg-fx::before` را پاک کن.

### فونت
فونت وزیرمتن است: `src/assets/fonts/`. برای فونت دیگر، سه خط `@font-face` اول فایل CSS را عوض کن.

## ۴) مودال و اعلان‌ها را می‌خواهی سفارشی کنی؟

همه در `src/assets/js/ui.js` است:
- `tlToast(متن، نوع، {title, duration})` → اعلان (نوع‌ها: `ok`, `err`, `warn`, `info`)
- `tlAlert(متن، نوع، عنوان)` → مودال اطلاع
- `tlConfirm(متن، {okText, danger, icon, title})` → مودال تأیید (با `danger: true` دکمه قرمز می‌شود)
- `tlPrompt(...)` → مودال با فیلد ورودی

هر فرمی که `data-confirm="متن سوال"` داشته باشد، خودکار پرسش حرفه‌ای می‌گیرد (نه confirm زشت مرورگر).

مثال استفاده در هر صفحه:
```html
<button onclick="tlToast('قالب منتشر شد', 'ok', {title:'انجام شد'})">تست</button>
```

## ۵) آپلود روی گیت‌هاب (گام‌به‌گام)

**قدم ۱:** GIT نصب باشد (git-scm.com).

**قدم ۲:** در ترمینال داخل پوشهٔ پروژه:

```bash
git add -A
git commit -m "نسخه 2.0 — پوسته نئون ریفت: مودال حرفه‌ای، اعلان، صفحه‌بندی نئونی، پنل ادمین جدید"
```

**قدم ۳:** به ریپوی خودت وصل کن (آدرس ریپو را از گیت‌هاب کپی کن):

```bash
git remote add origin https://github.com/aliradinpa-glitch/apptheme.git
git push -u origin main
```

> اگر `main` خطا داد: `git push -u origin master` را امتحان کن.

## ۶) گرفتن ZIP و انتقال به هاست

- کل پوشهٔ پروژه (به جز `data/` دیتابیس) را ZIP کن.
- در هاست کافیست `node server.js` را اجرا کنی (Node نسخه ۱۸ به بالا).
- دامنه: `SITE_URL=https://example.com node server.js`
- پورت دلخواه: `PORT=8080 node server.js`

## ۷) فایل‌هایی که این نسخه تغییر داده

```
server.js                          ← اسلش انتهایی + صفحه ۴۰۴/خطای نئونی
src/assets/css/app.css             ← بازطراحی کامل فروشگاه (نئون ریفت)
src/assets/css/admin.css           ← بازطراحی کامل پنل ادمین (نئون ریفت)
src/assets/js/ui.js                ← کیت مودال/اعلان حرفه‌ای (کاملاً جدید)
src/assets/js/app.js               ← دراپ‌داون کاربر، تم، کشوی سبد نئونی
src/assets/js/admin.js             ← زنگ اعلان، سایدبار موبایل، تم
src/render.js                      ← ناوبار، فوتر، مودال ورود، پوستهٔ ادمین با اعلان
src/routes/admin.js                ← صفحه‌بندی نئونی + صفحه‌بندی مشتریان/پروژه‌ها
src/routes/public.js               ← صفحه‌بندی نئونی فروشگاه
src/util.js                        ← ۴ لایوت بندانگشتی قالب‌ها
```

## ۸) نکات حرفه‌ای (اگر خواستی جلوتر بروی)

1. **موبایل**: پنل ادمین در موبایل سایدبارِ کشویی دارد؛ دکمهٔ ☰ بالای صفحه.
2. **تم‌ها**: دکمهٔ آفتاب/ماه در ناوبار و توپبار — انتخاب کاربر ذخیره می‌شود.
3. **دسترس‌پذیری**: اگر کاربر «کاهش حرکت» را در سیستمش فعال کرده باشد، همهٔ انیمیشن‌ها خودکار خاموش می‌شوند.
4. **حجم**: هیچ کتابخانهٔ خارجی اضافه نشده؛ همین CSS/JS خالص است.
