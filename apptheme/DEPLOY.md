# 🚀 دیپلوی اپ‌تم — راهنمای کامل (فارسی)

## ⚡ شروع سریع (۳ دقیقه)

```bash
# ۱) فایل را باز کنید و اجرا:
node server.js
# ۲) مرورگر: https://apptheme.ir/setup  →  حساب مدیر با ایمیل واقعی خودتان بسازید
# ۳) ادمین → تنظیمات → «شروع واقعی» → دکمه حذف داده‌های دمو
# ۴) ادمین → قالب‌ها → قالب‌های نمونه را ویرایش/حذف کنید و قالب‌های خودتان را بگذارید
```

## 💳 فعال‌سازی و تست زرین‌پال (وقتی مرچنت‌کد گرفتید)

1. ادمین → تنظیمات → پرداخت: حالت **«زرین‌پال»** + مرچنت‌کد (UUID) → اول چک‌باکس **Sandbox** را بزنید → ذخیره
2. مطمئن شوید `SITE_URL=https://apptheme.ir` ست شده (کال‌بک خودکار: `SITE_URL/payment/callback`)
3. با یک حساب کاربری، یک قالب بخرید → باید به صفحه زرین‌پال (سندباکس)	redirect شوید
4. پرداخت آزمایشی را کامل کنید → بازگشت به سایت → صفحه «پرداخت موفق» + لینک دانلود فعال ✓
5. ادمین → سفارش‌ها: سفارش باید «پرداخت شده» با کد پیگیری زرین‌پال باشد
6. اگر همه‌چیز اوکی بود: چک‌باکس Sandbox را بردارید → درگاه واقعی فعال ✅

> خطای احتمالی: اگر پس از پرداخت به تسویه برگشتید با پیام «اتصال به درگاه ناموفق»، یعنی Verify پاسخ نداد — لاگ سرور را ببینید (خطای `[zarinpal]` با کد خطا) و مرچنت‌کد/مبلغ را چک کنید.


## چرا مهاجرت راحته؟

- **صفر وابستگی npm** → نه `npm install`، نه شکستن پکیج‌ها. فقط `node server.js`
- **همه داده‌ها در یک فایل**: `data/db.json`
- **پشتیبان/بازیابی از خود پنل ادمین** → تنظیمات → «دانلود پشتیبان» / «بازیابی»
- فایل‌های آماده: `render.yaml` (رایگان)، `Dockerfile` (هر جا)

> ⚠️ **نکته مهم هاست رایگان:** دیسک اکثر پلن‌های رایگان **موقتی** است؛ با ری‌استارت/دیپلوی دوباره، `data/db.json` پاک می‌شود.
> راه حل: هر چند روز از پنل ادمین بکاپ بگیرید (داشبورد یادآوری می‌کند). برای مهاجرت هم فقط همین فایل را در هاست جدید «بازیابی» کنید.

## گزینه ۱: Render.com (پیشنهادی — رایگان)

1. کد را در یک ریپوی **گیت‌هاب خصوصی/عمومی** بگذارید (پوشه `themeland` را همان طور)
2. در [render.com](https://render.com) → **New → Web Service** → ریپو را وصل کنید
3. Render به‌صورت خودکار `render.yaml` را می‌خواند. فقط این را تنظیم کنید:
   - Environment Variable: `SITE_URL=https://yourname.onrender.com`
4. Deploy! تمام. (پلن رایگان بعد از ۱۵ دقیقه بی‌فعالیتی می‌خوابد؛ اولین بازدید ~۳۰ ثانیه طول می‌کشد)

### ⚠️ حیاتی: دیسک پلن رایگان Render موقت است!

هر ری‌استارت/دیپلوی، کل `data/db.json` (کاربران، سفارش‌ها، لایسنس‌ها، تنظیمات زرین‌پال) را پاک می‌کند.
راه‌حل داخلی برنامه: **سینک خودکار با ریپوی خصوصی گیت‌هاب** (رایگان):

1. در گیت‌هاب یک ریپوی **خصوصی** خالی بسازید؛ مثلا `apptheme-data`
2. یک توکن بسازید: Settings → Developer settings → Fine-grained tokens → Generate:
   - «Repository access» → فقط همان ریپو
   - «Permissions → Contents» → **Read and write**
3. در Render → Environment دو متغیر را اضافه کنید:
   - `DB_SYNC_REPO` = `username/apptheme-data`
   - `DB_SYNC_TOKEN` = توکن ساخته‌شده
4. Save → از این پس: در بوت اگر دیتابیس محلی نبود، **خودکار از گیت‌هاب بازیابی** می‌شود؛ و هر تغییری (ثبت‌نام/سفارش/تنظیمات) **خودکار (تا ۱۲ ثانیه بعد) در گیت‌هاب ذخیره** می‌شود. لاگ موفقیت: `[db-sync] ✓`

> تست‌شده: سناریوی کامل بازیابی و ذخیره خودکار در سوئیت تست (بخش ۱۶ — ۱۰۰/۱۰۰).

## گزینه ۳: هر هاست با Docker

```bash

```

## گزینه ۴: VPS (استقرار حرفه‌ای — پیشنهادی)

> راهنمای مبتدی‌پسند کامل: **[GUIDE.md](GUIDE.md) → بخش ۴** (قدم‌به‌قدم با PM2 و SSL)

```bash
# ۱) Node 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt-get install -y nodejs
# ۲) پروژه
cd /opt && git clone https://github.com/aliradinpa-glitch/apptheme.git && cd apptheme/apptheme
# ۳) PM2 (دائم روشن + خودکار بعد از ریبوت)
npm i -g pm2
pm2 start ecosystem.config.js   # SITE_URL و PORT را داخل این فایل بگذار
pm2 save && pm2 startup
# ۴) SSL خودکار با Caddy
apt-get install -y caddy && echo "YOUR-DOMAIN.com { reverse_proxy 127.0.0.1:3000 }" > /etc/caddy/Caddyfile && systemctl restart caddy
```

### مهاجرت از هاست رایگان به هاست جدید (۳ دقیقه!)

1. در هاست قدیم: ادمین → تنظیمات → **دانلود فایل پشتیبان**
2. هاست جدید را بالا بیاورید (هر روش بالا)
3. در هاست جدید: `/setup` → حساب مدیر با **همان ایمیلی که در بکاپ دارید** بسازید
4. ادمین → تنظیمات → **بازیابی از فایل** → فایل را بدهید → تمام ✓
   (همه چیز برمی‌گردد: قالب‌ها، سفارش‌ها، کیف پول‌ها، پیام‌ها، تنظیمات)
